# Project instructions

- **Keep it simple:** Use plain HTML, CSS, and JavaScript. Don’t add frameworks or dependencies unless asked.
- **File organization:** Keep the demo in `index.html`, `style.css`, and `script.js`.
- **Explain changes:** Explain what changed and why using language suitable for students learning to code.

At the end of each work session, remind the user to commit and push their changes so their work is saved in Git and backed up to the remote repository.

Keep the reminder brief. This instruction is a reminder only; do not automatically commit or push unless the user asks. If all work has already been committed and pushed during the session, acknowledge that instead.
